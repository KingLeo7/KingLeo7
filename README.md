# 💫 About Me:

My work focuses on cybersecurity and system protection using key tools:<br><br>
🔹 Network scanners like Nmap to detect vulnerabilities.<br>
🔹 Wireshark for packet analysis.<br>
🔹 Metasploit for penetration testing.<br>
🔹 Firewalls to block unauthorized access.<br>
🔹 Antivirus and endpoint security tools.<br>
🔹 SIEM systems for monitoring threats.<br>
🔹 Password managers for secure credentials.<br><br>
These tools help identify risks, protect data, and ensure system integrity in a constantly evolving digital threat landscape.
